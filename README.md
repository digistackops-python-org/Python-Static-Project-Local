# Install python3
```
sudo yum update -y
sudo yum install python3 -y
sudo yum install python3-pip -y
```


# Start your Application
```
git clone https://github.com/techizone-Small-Project-org/Python-Static-Project.git
cd Python-Static-Project
git checkout 01-Local-setup
pip install -r requirements.txt
python3 run.py
```
